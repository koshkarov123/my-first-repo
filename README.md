## О проекте

Данный репозиторий содержит исходный код статического сайта-визитки. Проект создавался для закрепления навыков работы с терминалом Git Bash, основами верстки и системой контроля версий Git.

> [!NOTE]
> Все коммиты в проекте оформляются по соглашению Conventional Commits: `feat:`, `fix:`, `docs:`.

Ранее верстка велась вручную через Проводник исключительно через терминал и горячие клавиши.
